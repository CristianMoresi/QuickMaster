# QuickMaster 1.3.2

This release replaces the withdrawn 1.3.1 release.

## Limiter correction

- The route is **Multiband → Broadband → Peak Normalizer** (when enabled).
- Both limiting stages share the Limit module's input-peak reference. Adding
  multiband drive no longer raises the broadband ceiling and loses its effect
  through output normalization. Broadband Push stays independent.
- Smooth offline lookahead and calibrated release replace the previous
  depth-dependent timing. The GR display reports actual attenuation, including
  upstream drive; Push is input gain, not a maximum GR setting.
- Rendered true peaks are checked, including the end of the file. The final
  Peak Normalizer remains responsible for the selected delivery ceiling.

## Other improvements since the previous public release

- Upward-only macro RMS Leveler with editable red waveform exclusions,
  undo/redo and per-track persistence.
- The waveform follows the processed audio, Bypass and A/B selection.
- Faster A/B preparation reuses only exact, valid audio; shared edits correctly
  invalidate cached results.
- Intervening playback, analysis, export and DSP corrections from the local
  product audit are included.

## Downloads

Download and extract the ZIP for your operating system. The application is
portable and includes Java 25; there is no installer. The core JAR is provided
for reproducibility, not as a standalone application. SHA-256 checksums are
provided alongside the bundles.

Validation details and limitations are recorded in
[`docs/diagnostics/limiter-cascade-audit.md`](https://github.com/CristianMoresi/QuickMaster/blob/main/docs/diagnostics/limiter-cascade-audit.md).
