## Installed acceptance

- **371 tests** passed against the installed JAR, with no failures, aborts or
  skips. Diagnostic classes resolve application code from the installed JAR,
  not `target/classes`.
- Real FXML/controller with By Now: Generation defaults/resets to 25%; sections
  start off; Low Cut/Side Gain readouts open no dialogs. **41 mono switches**
  preserve render identity, source, settings, position and analysis generation.
  Stereo output matches an independent cold render bit for bit. Normal and
  compact interface screenshots were visually reviewed.
- Silent AudioPlayer PCM16 probes with **By Now** and **Quiet Gold**: 22 switches,
  131,073 frames and 217,090 settled samples checked per song. Maximum error is
  below 0.000046, within the dither/quantization tolerance. Sources are untouched;
  no audio is sent to a Windows output device.
- Full-track Leveler checks at 50% and 100% pass on both songs. At 100%, the
  fixed-grid 3-second RMS P10–P90 spread falls from **9.95 to 0.81 dB** in By Now
  and **6.72 to 1.05 dB** in Quiet Gold. Respectively 159 and 117 windows receive
  more than 1 dB of lift. No downward gain or hidden global trim; the maximum
  input macro-RMS reference is not exceeded.
- Stereo Generation passes **12 excerpt cases** across both songs, with/without
  generated bass: strong new decorrelated delta and no hidden overall/Mid trim.
- **Six routing cases** combine Stereo Image, EQ, compression, both clippers,
  multiband/broadband limiting and normalization, at 1x/4x oversampling. Output
  remains finite and source-aligned; all cases meet the -1.0 dBTP ceiling.

## Scope

The Windows portable is executed locally. macOS/Linux packages are built on
their native CI runners and their contents verified; no macOS/Linux GUI session
is claimed. Installed diagnostics use Temurin 25.0.4.7 with the delivered JARs;
the EXE startup check uses the bundle's runtime. Official loudness evidence
covers the stated file-measurement profile, not an unrestricted certification.
Numerical audio tests do not substitute for human listening. Private audio and
licensed test signals are not redistributed.

Local working evidence: `dist/release-1.3.3-20260929/`. The preceding accepted
development build is documented in `../diagnostics/mono-monitor.md`.
