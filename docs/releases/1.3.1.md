## QuickMaster 1.3.1

- **Structural Leveler:** levels comparable musical sections with smooth
  transitions while protecting intros, outros, breaks and build-ups. Ambiguous
  or peak-unsafe material is left unchanged. Fixes over-protection that could
  incorrectly classify a whole song as a build-up and prevent any correction.
- **Beat Comp:** respects the maximum reduction, improves stereo onset and tempo
  detection, and makes uncertain tempo estimates visible.
- **Waveform navigation:** wheel to pan without changing playback; Ctrl + wheel
  to zoom (Command on macOS). Alt + wheel over a fade handle edits its curve.
- **Faster editing:** makes the updated audio available before finishing meters,
  cancels obsolete analysis and reuses buffers and cached features. Rapid edits
  no longer accumulate full-track analysis jobs. Pending playback, failed loads
  and source changes preserve the latest valid settings.
- **DSPark Java 0.2:** audited FFT, oversampling, smoothing and true-peak kernels,
  with C++ reference checks. Existing EQ voicing and offline dynamics are preserved;
  this is not a port of every feature in the C++ library. Also includes corrected
  loudness measurement, sample-rate conversion and dither.

On the validation machine with a 280-second stereo track, Leveler-only edits
made audio ready in a median 1.74 seconds (previously 7.35 seconds); full-chain
edits took a median 3.50 seconds over 20 changes. Initial track analysis remains
more expensive. These measurements are workload-specific, not a timing guarantee.

### Downloads

Download the ZIP for Windows, macOS or Linux, extract the complete folder and run
QuickMaster. Java is bundled; no installer is needed. Keep the executable with
its accompanying folders. The `core` JAR is a verified build input, not a
standalone application.

Packages: Windows x64, Linux x64 and macOS Apple Silicon (arm64). The macOS ZIP
is not an Intel build. Download checksums are provided in
`1.3.1-SHA256SUMS.txt` alongside the packages.

### Validation

The release JAR passes 715 application tests, alongside 122 DSPark tests,
106 musical variants and 94 official ITU/EBU file-loudness measurements.
Real-track Leveler correction, the Beat Comp reduction cap, waveform navigation,
rapid edits and failed-load recovery were checked against the installed Windows
application. No human listening assessment is claimed.

Platform packaging verifies the exact JAR hash and its bound conformance report.
The Windows ZIP contains the locally validated Temurin 25 application image;
macOS and Linux are packaged in CI with Temurin 21 and are not claimed to have
received native interactive testing on the Windows validation machine.
This is not complete EBU Mode certification or infallible recognition of musical
intent. Official test audio and personal authorizations are not distributed.
