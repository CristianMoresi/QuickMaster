# QuickMaster 1.3.4 — release validation

Status: all release gates passed; published on 2026-09-29.

[QuickMaster 1.3.4](https://github.com/CristianMoresi/QuickMaster/releases/tag/v1.3.4)
replaces the removed 1.3.3 GitHub release. The `v1.3.3` Git tag and its source
history are retained. The previous release's metadata, packages and checksums
are preserved locally for recovery; no other historical releases were removed.

This release finalizes the accepted 1.3.4-SNAPSHOT build. The complete suite,
including the authorized ITU/EBU file-measurement corpus, is rerun after setting
the release version. CI packages the exact validated core JAR, not a rebuild.

The [MP3 port audit](../diagnostics/mp3-decoder-port.md) and
[EQ display audit](../diagnostics/eq-spectrum-tilt.md) record the implementation
and pre-release evidence. The results below refer to the final release artifact.

## Installed acceptance

- **386 regression tests** pass against installed JARs, with no failures,
  aborts or skips. Application code resolves from the installed JAR, not
  `target/classes`.
- **97 MP3 comparisons** pass against independent float references: the
  96-format matrix and the private full-length By Now derivative. That track
  yields 13,440,001 stereo frames at 48 kHz, maximum sample error 3.189e-6
  and relative error -123.322 dB; source bytes remain unchanged.
- The real FXML/controller imports that MP3 and passes the display-only slope
  check: **4.5 dB/octave, 1 kHz pivot**, unchanged PCM/render/preset/measurements
  and no analysis triggered by drawing. Normal/compact screenshots were reviewed.
- Mono UI and PCM16 switching probes pass on By Now and Quiet Gold. Generation
  defaults to 25%; value labels open no dialogs. Mono monitoring preserves
  render identity and does not trigger analysis. No Windows audio device is used.
- Full-track Leveler checks at 50% and 100% pass on both songs. At 100%, the
  fixed-grid 3-second RMS P10–P90 spread falls from **9.95 to 0.81 dB** in By Now
  and **6.72 to 1.05 dB** in Quiet Gold. Respectively 159 and 117 windows receive
  more than 1 dB of lift. No downward gain or hidden global trim; the maximum
  input macro-RMS reference is not exceeded.
- **12 Stereo Generation excerpt cases** across both songs pass, with and
  without generated bass: strong new delta, unchanged original Mid and no
  hidden whole-mix attenuation.
- **Six routing cases** combine Stereo Image, EQ, dynamics, clipping and limiting
  at 1x/4x oversampling; all remain source-aligned and meet the -1.0 dBTP ceiling.

## Scope

The Windows EXE is launched locally with its bundled runtime. Installed numerical
diagnostics use Temurin 25.0.4.7 and the delivered JARs. macOS/Linux packages are
built on native CI runners and inspected; no macOS/Linux GUI session is claimed.
Official evidence covers the stated file-measurement profile, not unrestricted
certification. Numerical checks do not substitute for human listening.

CI reports nonblocking deprecation warnings for the existing checkout/setup-java
v4 actions; all packaging jobs pass. A future workflow-maintenance change should
update those actions independently of this accepted release.

Local working evidence: `dist/release-1.3.4-20260929/`.
Private audio and licensed test signals are excluded from Git and downloads.
