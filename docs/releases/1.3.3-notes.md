# QuickMaster 1.3.3

## Stereo Image

- New independent Generation, Side Leveler and Side Guard sections, placed
  before Dynamics by default. All start off; Generation starts at 25%.
- Generation combines moving differential EQ, delta-only saturation and
  harmonics while preserving the original Mid. Amount ranges from subtle to pronounced.
- Generated Stereo Low Cut runs from Off to 5 kHz, with linear-phase filtering
  of the generated difference only. Independent Side Gain adjusts the final
  Side from -12 to +12 dB. Slider values never open popup windows.
- Auto balance, ten measured genre references and local reference import.
  Profiles describe energy, not a universally ideal stereo image.
- Full-quality synthesis/filter caches and cancellable previews speed up
  compatible edits. The first analysis still requires offline computation.

## Audition and EQ

- Listen in mono below the Mid/Side meters, with smooth switching and no
  reanalysis. It applies to preview, Bypass and A/B without changing export.
- EQ band edits can be auditioned while the exact full master is computed in
  the background. Provisional previews are labelled and never used for export.
- Optional DSPark K-weighted EQ Auto Gain compensates level without saturating
  the signal. Its readout stays blank when no compensation is displayed.

## DSP corrections

- Updated DSPark Java 0.2.3 with native-verified Auto Gain, clipping curves and
  offline SuperFlux onset detection.
- Corrected Peak Comp boundary handling and Punch attack detection.
- Calibrated soft/hard clipping with actual rendered gain-reduction metering,
  saved Hard/Soft selection and explicit oversampling for alias reduction.
- Strong stereo generation does not silently turn down the whole mix. Use
  Limit / Peak Normalizer explicitly when output headroom is required.

## Downloads

Download and extract the ZIP for Windows, macOS or Linux. Each portable includes
Java 25; there is no installer. The core JAR is a reproducibility artifact, not
a standalone portable application. SHA-256 checksums accompany the bundles.
